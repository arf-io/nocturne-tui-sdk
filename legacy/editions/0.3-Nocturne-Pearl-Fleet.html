What is live here?
Telemetry is a deterministic synthetic source, labeled as such. The plots draw those samples. Messages are stream events, not a prerecorded movie. Motion aims at 30 Hz. Input/data repaint synchronously at the last sampled motion time.
Holding motion reveals incoming text immediately. Returning to live tail is explicit when you have scrolled into history. Pausing demo data is independent of pausing motion.


All art inside the terminal is emitted cell geometry: braille, line art, blocks and RGB ink. No shader, blur, glow, or CSS transformation is added to its animation.
