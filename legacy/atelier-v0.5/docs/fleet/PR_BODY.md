## Pearl Fleet

Adds an expert fleet deck and maximized agent conversations around the Pearl Signal visual language. New text fades in; upper transcript rows soften; input/data remain independent of 30-FPS decorative scheduling.

Includes reusable controller/model, browser and terminal hosts, per-agent drafts/history, explicit source and command descriptors, native normalized-scene importers, a shared C opacity helper exposed to all four bindings, tests and documentation. Old ABI and fixtures remain intact.

Local execution: native/Python/Go/WASM contracts and parity, browser, terminal PTY and sanitizers passed. Rust sources/tests reviewed but not executed locally because Cargo/rustc were unavailable. The required Rust CI job must pass before treating the release as Rust-verified. No live provider, tmux or AFD integration claim.
