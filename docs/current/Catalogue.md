# Component catalogue

This catalogue lists 109 of the 111 native catalogue identities in four families; the 2 identities hidden by the contract are listed on the [nullification page](Nullification.md) instead. An identity is the value of the `effect` field of the commands listed for its family. Each family page lists the parameters of those commands with their defaults and domains, then one entry per identity with commands the library accepts and refuses. The [component atlas](Components.md) shows captured states of the visible components.

A source identity names the original effect an identity comes from. Profile is 1 when the source identity is under an Atelier source and 0 otherwise.

A hidden identity is omitted from these pages and from the Gallery. The core still accepts and renders it, so the parameter tables include it.
